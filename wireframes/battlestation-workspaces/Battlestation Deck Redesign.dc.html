Battlestation · The Deck — redesign

A calmer, legible work-queue for you and your agents

One Deck, two interchangeable views — a fast triage Queue and a kanban Board (toggle top-right). Both prioritise globally across all projects by default, and both can filter down to a single workspace with the project chips. Metadata is typed chips, urgency reads as a left accent bar, and every running harness keeps its own personality icon that changes colour with its live status — thinking, tool use, waiting. Global Inject and Auto-retrigger live in the header. Everything below is live.

1a Queue · global priority triage

One ranked list across every project — blocking items float to the top, then urgency, so you always work the single most important thing next. Tap a project chip to narrow to that workspace. Expand a card for one-tap answers, reply, tag or dismiss.

1b Board · flow across statuses

The same items as columns — Inbox → Working → Blocked → Done — with "blocking" kept as an orthogonal ▹ flag rather than a lane. Global by default; use the same project chips to focus one workspace. Agents move their own cards; you drag to reprioritise.
