# packages/pacman.txt — DELIBERATE additions: native packages installed on
# purpose, on top of the CachyOS installer baseline (packages/pacman-base.txt).
#
# Format: one package name per line; `#` starts a comment (full-line or
# trailing) — the same parse bin/drift and bin/install-packages use.
# bin/drift diffs base+this against `pacman -Qqe --native`; `make
# install-packages` applies both with `pacman -S --needed`.
#
# Every entry carries a why (setup-note entries cite their note). Dependencies
# of a declared package are NOT listed — drift compares the explicit set only.
# A new install means a line HERE; pacman-base.txt only changes when
# re-baselining against the installer. Never paste a `pacman -Qqe` dump:
# triage new drift-report entries one by one, and leave anything unclear OUT
# so it stays visible in `make drift`.
