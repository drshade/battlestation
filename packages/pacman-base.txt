# packages/pacman-base.txt — the ACCEPTED BASELINE: the explicit native
# package set as the CachyOS installer left it (snapshot 2026-07-02), minus
# anything we've deliberately removed or reclassified.
#
# Same format/parse as packages/pacman.txt. bin/drift diffs the union of both
# files against `pacman -Qqe --native`; `make install-packages` applies both.
#
# Nothing NEW belongs here: a deliberate install goes in pacman.txt with a
# `# why`. This file changes only when re-baselining (a fresh installer
# defaults sweep) or when a baseline package is deliberately dropped. Most of
# these were chosen by the installer, not by hand — declaring them keeps the
# drift report quiet so *new* explicit packages stand out.
