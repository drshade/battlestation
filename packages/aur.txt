# packages/aur.txt — declared AUR / foreign packages.
#
# Format: one package name per line; `#` starts a comment — same parse as
# packages/pacman.txt. bin/drift diffs this against `pacman -Qqm`;
# `make install-packages` applies it with an AUR helper (paru/yay) if one
# is installed.
#
# If a foreign package shows up in `make drift`, either declare it here
# (with a why, if it's core to every machine), exclude it in
# packages/aur-ignore.txt (personal / machine-local), or remove it.
